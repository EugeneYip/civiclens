# CivicLens 選舉資訊作業手冊

本手冊記錄 115 年（2026-11-28）地方公職人員選舉暨全國性公民投票第 22 案的完整作業模式，涵蓋選前資料建置、投票日、開票夜及開票後封存，供下次選舉（最早為 2028 年 1 月總統副總統及立法委員選舉）直接沿用。各段所列網址格式、檔案與指令，均為 2026 年實際使用並驗證過的作法；中選會網站格式每屆可能調整，沿用前務必重新實測。

## 一、基本原則（不得妥協）

1. **只用官方或可追溯來源**：中選會、各縣市選委會、法規資料庫、內政部。第三方資料只用於輔助定位，必須標示來源與限制，不得直接取代官方資料。
2. **不推測**：
   - 票數不估算、不補值；開票數字只取中選會計票網站。
   - 當選以中選會標示為準，不依得票排序推定。議員選舉另有婦女保障名額，排序與當選不一定相同。
   - 未取得的資料一律標示為「尚未」，不寫成「沒有」。
3. **逐字與如實呈現**：
   - 公報政見逐字轉錄，錯字與異體字照原樣保留。
   - 標語、空白、「無」字都如實描述；對無法辨讀的公報，明說原因。
4. **隱私**：
   - 公報所印的私人電話與服務處地址不轉錄。
   - 指涉可辨識第三人違法的內容不刊登全文。
   - 身分證樣式字串在合併階段即擋下。
5. **中立**：
   - 同意與不同意採相同樣式；政黨顏色僅用於地圖與標示。
   - 用語不帶立場；候選人排序依號次或得票數。
6. **每次變更都要驗證**：單元測試、瀏覽器測試與 GitHub Actions 全部通過後才併入 main，並實測正式網站，確認檔案與提交版本逐位元組相符。
7. **對外文字**：網站內容與回報一律使用正式臺灣正體中文。

## 二、時程總覽與檢查清單

| 階段 | 時點（2026 實際） | 主要工作 |
|---|---|---|
| 公告期 | 投票日前約 90–30 天 | 選舉公告、候選人登記、名冊、選舉人數 |
| 公報期 | 投票日前約 14–10 天 | 選舉公報上網 → 政見逐字轉錄、學經歷判讀、照片 |
| 公投期 | 投票日前 90–28 天 | 公投主文、理由書、公報、意見發表會（5 場） |
| 投票前 1 週 | 11/21–11/27 | 全站稽核、斷行與版面、投票須知與攜帶物提醒 |
| 投票日 | 11/28 08:00–16:00 | 首頁倒數、攜帶提醒（16:00 自動隱藏） |
| 開票夜 | 16:00–24:00 | 確認開票 → 匯入 → 每 8–10 分鐘更新 → 地圖 |
| 開票後 | 隔日起 | 中選會標示當選或審定公告後補正式結果、封存 |

### 選前檢查清單
- [ ] 22 縣市公報目錄、各選區 PDF 直達連結（bulletin.cec.gov.tw）
- [ ] 名冊逐筆比對中選會選舉專區（號次、姓名、推薦政黨、性別）
- [ ] 首長及議員政見全文：轉錄、覆核、隱藏字型稽核、合併防護
- [ ] 公投：主文、理由書全文、投票權人數、門檻計算、公報各項（含罰則摘錄）、意見發表會
- [ ] 介面：手機 360/390/430 及桌面 1280 截圖逐頁檢視，axe 無障礙檢測
- [ ] 排程：投票日 16:30 檢查開票是否正式開始（未開始則 30 分鐘後再查）

### 開票夜檢查清單
- [ ] 確認中選會計票網站上線，且至少一選區「已送投票所數」大於 0
- [ ] 執行 adapter，確認 243 個選區頁面全數取得，且得票率逐列核對無誤
- [ ] builder 全數通過名冊比對，姓名差異逐一人工判定（見第五節）
- [ ] 部署並實測，啟動定時更新迴圈並以監看工具追蹤
- [ ] 首頁地圖、公投區塊、結果頁的用語隨狀態正確切換

## 四、選前資料建置

### 4.1 名冊與基本資料
- 臺北市以公告名冊為準，其他縣市以全國補充名冊為底，再逐筆比對中選會選舉專區（`scripts/import_cec_official.py`），核對號次、姓名、推薦政黨、性別與出生年。
- 開票夜另以計票網站逐筆複核政黨與性別，1,574 人全數一致。

### 4.2 公報政見全文
1. **轉錄**：依 `docs/playbook/transcription-prompt.md` 分批交由轉錄代理處理。
2. **覆核**：依序進行文字層比對、影像抽查（`scripts/transcription/crop_cand.py`）及隱藏字型稽核（`scripts/transcription/font_gap.py`）。poppler 會把部分 CID 字型渲染成空白，必須以 pdfium 交叉比對。
3. **合併**：以 `scripts/transcription/merge_council_full.py` 合併，並重建縣市分片（`scripts/build_county_shards.py`）。
4. **成果**：首長 81 人（1,405 項）、議員 1,474 人（16,927 項）。其餘 19 人：
   - 9 人公報只印標語、QR 碼、「無」字或空白，頁面照錄標語並如實說明。
   - 8 人原圖模糊，無法逐字確認。
   - 2 人內容指涉第三人違法。
5. **學經歷**：以本站判讀版本為準；民間轉錄僅供比對，因其可能缺漏（例如 2026 年曾發現民間版缺漏兩筆經歷）。

### 4.3 公投資訊（站內完整呈現）
- **主文與理由書**：理由書依中選會公告逐字收錄。
- **基本數據**：投票權人數（20,003,835 人）及門檻（四分之一，5,000,959 票），計算依據為公民投票法第 29 條；通過後效果依第 30 條。
- **公報各項**：資格、攜帶證件、投票所注意事項（含第 41、43 條）、公投票式樣、無效票情形，以及與投票權人直接相關的罰則摘錄（第 42、44 條、刑法第 143 條）。
- **意見發表會**：5 場，含日期、頻道、主持人與正反方代表，影片可站內播放。
- 立法院提案（第 15 條第 2 項）不適用政府機關意見書，公報因此沒有該項。

### 4.4 介面與呈現
- **版面**：手機優先，主要寬度 360/390/430，並檢視桌面 1280。
- **比較頁**：手機同列並排，政見全文可收合，主題選項標示「n 人提及」。
- **依詞斷行**：`scripts/phrase.js` 以 `Intl.Segmenter` 加上 `<wbr>`，搭配 `word-break: keep-all`。在 flex 或 grid 容器內須以 span 包住，設為 nowrap 的文字則略過。
- **短句分句**：公投主文等短句依逗號分句，加上 `.clause` 類別。
- **展開箭頭**：可展開區塊一律使用右側箭頭，避免卡片看起來像空白。
- **攜帶提醒**：國民身分證、印章、投票通知單，投票截止後自動隱藏。

## 五、開票夜作業

### 5.1 開票是否正式開始
- 只有官方計票頁「已送投票所數」大於 0，才算開始公布票數。網站上線但全為 0（2026 年 16:33 的狀態）時不匯入，30 分鐘後再查。
- 2026 年首批票數出現於 17:05。

### 5.2 計票網站結構（vote.cec.gov.tw，2026 實測）

**入口**
- 地方選舉：`/2026-local/zh-TW/indexP.html`
- 公投：`/2026-ref/zh-TW/indexP.html`

**選區樹**：`/2026-local/assets/def/tree-compiled.2026-local.min.json`。
- 縣市節點的 `serial.c` 為 5 碼縣市代碼。
- 議員選區節點為精簡陣列 `[類型, 序, "選區碼", …]`。
- 類型 4 的節點另附範本鍵（例如 `rbd0`、`sbd0`），範本會把前綴改為 T2（平地原住民）或 T3（山地原住民）。

**頁面網址**：`{prefix}/{c 5碼}{選區 2碼}{鄉鎮 3碼}{村里 3碼}{投票所 4碼}.html`。
- 縣市長：`TC/{c}000000000000.html`
- 議員：`T1|T2|T3/{c}{選區}0000000000.html`
- 公投全國：`F1/00000000000000000.html`

**頁面內容**：一般 HTML 表格。
- 欄位：號次、姓名、性別、得票數、得票率%、推薦之政黨。
- 另列「已送投票所數/總投票所數」與「資料更新時間」，每分鐘更新。

**解析陷阱**：比對表頭的規則須寫成 `<th\b`，否則會誤抓 `<thead>`。

**當選標記**：計票網站整晚都沒有標示當選，包括已全數送達的選區。頁面上唯一出現「當選」二字的是「婦女應當選名額」，不可誤判為當選標記。

### 5.3 資料流程與檢核

**`scripts/adapt_cec_vote.py`（取得與轉換）**
- 依選區樹組出 243 頁（22 首長＋221 議員），每頁輸出一份正規化 JSON，來源為該頁網址。
- 有效票以候選人得票合計計算，並逐列核對中選會的得票率（誤差 ±0.011%）。
- 只有全部投票所送達、且頁面標示當選人數等於應選名額時，才列為最終結果。

**`scripts/build_results_snapshot.py`（名冊比對）**
- 逐筆比對本站名冊的號次與姓名。
- 姓名比對規則：
  - 異體字：黄／黃。
  - 原住民候選人附加羅馬拼音：漢字部分須完全相同，其餘只能是拉丁字母或標點。
  - 經人工判定的別名：彰化縣議員第 8 選區 9 號，選舉專區與公報作「洪建興」，計票網站作「洪健興」。
- 另保存已送投票所數；最終結果不會被開票中的資料覆蓋。

**其他產出**
- `scripts/build_referendum_result.py`：寫入前檢核同意＋不同意＝有效票、有效票＋無效票＝投票數、投票權人數與公告一致。全部送達後才依第 29 條判定是否通過。
- `scripts/build_results_map.py`：首頁地圖資料，每縣市只取得票最高者，同票則不列。

**網頁用語**（`scripts/results.js` 等）

| 狀態 | 網頁用語 |
|---|---|
| 開票中 | 「開票中（尚非最終結果）」 |
| 全部送達、未標示當選 | 「投票所已全部送達（中選會尚未標示當選；本站不自行判定）」 |
| 已標示當選 | 「開票完成（中選會已標示當選；正式當選以審定公告為準）」 |

### 5.4 定時更新與部署
- `scripts/ops/refresh_results.sh` 一次完成一輪：抓取 → 建置 → 測試 → 提交 → 推送 → 等候 CI → 快轉 main → 實測。任一步驟失敗就還原資料、不發布，並輸出一行狀態。
- 開票夜以迴圈每 8–10 分鐘執行一輪，並以監看工具追蹤 LIVE、FAIL、NOCHANGE 等狀態。
- 修改程式碼要避開更新迴圈的提交時段，以免 Git index 鎖衝突；較大的改版可先暫停迴圈。
- `scripts/ops/deploy.sh` 負責一般部署：等候 CI、快轉 main、輪詢正式網站的 VERSION 與指定檔案，直到逐位元組相符。
- 2026 年開票進度：17:05 首批，19:10 約 50%，20:35 約 91%，21:45 約 99%，23:47 剩 3 個投票所。

### 5.5 地圖
- **縣市地圖**：`scripts/build_map_geometry.py`。
  - 金門縣與連江縣以插圖呈現。
  - 須保留內環，例如新北市環繞臺北市、嘉義縣環繞嘉義市，並以 evenodd 填色；被環繞的縣市最後繪製。
  - 未保留內環時，同色的新北市會蓋住臺北市（2026 年 V0.1.85 修正）。
- **議員選區地圖**：`scripts/build_council_maps.py`。
  - 依選區組成合併鄉鎮界線；新竹縣竹北市與新竹市依村里合併。
  - 不屬任何村里的土地以灰底呈現，60 個原住民選區以按鈕列出。
  - 建置時檢查每個選區都有圖形、每塊圖形都有所屬選區。
- **上色規則**：開票中以淺色表示領先，全數送達以深色表示得票最高；中選會標示當選後才稱「當選」。議員選區在當選標示前不依政黨上色。

## 六、事故與教訓（2026）

| 事故 | 原因 | 處理與預防 |
|---|---|---|
| 資料更新 CI 失敗（22:17） | 臺北市長全數送達後，狀態改為「投票所已全部送達」，但瀏覽器測試只接受「開票中／開票完成」 | 測試改為涵蓋所有狀態；資料流程設計為 CI 未過不發布，網站未受影響 |
| 地圖上臺北市消失 | 縣市圖形只取外環，新北市覆蓋臺北市 | 保留內環並以 evenodd 填色；兩種地圖一併修正 |
| 新竹市選區圖出現白洞 | 有一塊土地不屬任何村里（推測為機場一帶），且飛地方向相反 | 加入鄉鎮底圖，統一多邊形方向 |
| 政見誤列為非政見 | 誤判首段為與他段重複的橫幅 | 改列前必須先確認文字未在其他段落重複 |
| 「未能辨讀」用語不精確 | 公報標語其實清楚可讀 | 依公報實際內容照錄標語 |
| 中選會登記照無法嵌入 | 伺服器設定 CORP same-site | 保留原檔連結，不另行複製 |
| 官方圖資網站回應 403 | 拒絕本環境連線 | 改用可追溯的轉製來源並註明，不規避 |
| 部署驗證誤報檔案不符 | VERSION 未變時太早比對 | `deploy.sh` 改為輪詢直到相符 |
| 計票網站無當選標記 | 開票夜中選會未提供 | 不自行推定；以「投票所已全部送達」表示 |

## 七、2028 總統副總統及立法委員選舉沿用要點

**選舉性質差異**
- 總統副總統：全國單一選區、一組一票，政見為副總統搭檔聯合登記。
- 立法委員：區域 73 席、平地及山地原住民各 3 席，另有不分區政黨票。
- 可能同日舉行全國性公投，公投流程（第四節 4.3、第五節 5.3）可直接沿用。

**計票網站**
- 前綴、年份路徑與選區樹格式必須重新實測；可先用選區樹的 `serial`、`prefix` 推導網址，以 2026 年方法驗證。
- 不分區政黨票需另寫 adapter，處理政黨得票與席次分配，席次以中選會公告為準。

**地圖**
- 總統：沿用縣市地圖，依各縣市得票最高的候選人組別上色，並可加上全國得票比率。
- 立委：區域選區多數由鄉鎮組成，但跨鄉鎮切分村里的情形較多，需擴充 `build_council_maps.py` 的村里處理。

**名冊與公報**
- 候選人數較少，可提前全文轉錄並以影像逐人覆核。
- 公報格式（總統與立委）需重新檢視版面與文字層。

**排程**
- 投票日 16:30 檢查開票是否開始（30 分鐘重查），開票後每 8–10 分鐘更新。

## 十、開票後封存（歷史紀錄）

1. **確認狀態**：全部投票所送達後，再確認中選會是否標示當選或發布審定公告。若有，以 adapter 匯入當選標記；若計票網站不標示，改以 db.cec.gov.tw 的正式結果匯入，並另行驗證欄位。
2. **停止更新**：停止定時更新迴圈，保留最後一次官方數字及更新時間。
3. **封存標示**：網站改為歷史紀錄模式（2026 年於 V0.1.87 完成）。首頁開票區塊上方加註「歷史紀錄」說明；投票截止後隱藏攜帶提醒與投票所查詢；結果頁說明改為「已停止同步」。全部政見、公投與開票資料及原文連結均保留。
4. **文件**：更新本手冊與 `CHANGELOG.md`，記錄最終數字、未完成事項與已知限制。
