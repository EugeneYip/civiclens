# 資料與查核規格

## 現行資料

查核日期：2026-11-24（臺灣時間）。中選會官方電子公報目錄 22 個縣市連結均已逐一開啟確認；未逐份下載或查核其中所有公報。統計來自中選會「競選活動期間相關注意事項答客問」全國九類職務表。各列總數由測試重算。縣市地理區域是專案的瀏覽分類，不是選區邊界。選區應以中選會公告為準。資料不是即時資料；更新須重新查核。

## 候選人資料模型（未啟用）

以 election_id、jurisdiction_code、office_id、district_id、ballot_number 的複合鍵識別一次參選紀錄。跨屆人物識別需另有證據，不可僅憑同名合併。每個欄位具備來源 ID、文件連結、頁碼或定位、擷取日期、查核狀態、審查者及原始文句；候選人自述、官方確認事實、第三方主張與分析推估分開。未公開、未查得、無法確認、不適用均為不同狀態；未知非零。僅有正式證據才能標示已查證。

## 發布閘門（後續候選人資料）

1. 取得最終公告與更正文件；核對選區、職務、號次、身分及資料使用條件。保留來源版本及雜湊（若可合法保存）。
2. 每選區核對公告候選人總數與資料庫數量；處理撤銷、補登記、選舉延期等情形，不以最初登記名冊替代最終名單。
3. 自動擷取僅列待審；人員核對原始文件及定位，敏感欄位至少雙人覆核。缺漏或衝突明列，不發布未解決的指控。
4. 公開按職務、選區及政黨分組的資料覆蓋率及缺漏原因；分母來自官方名冊，不能以已匯入筆數當分母。
5. 法律、隱私、著作權、選舉期間規範與安全審查；確認更新、更正與申訴流程可用。
6. 版本化發布、回復與更正紀錄，保留必要稽核資訊；涉及個資的舊資料不得無條件公開。

## 敏感模組（尚未發布）

- 財產：原始申報值與估計值分開；本人／家庭範圍、日期、債務及估值區間明列。未能估值不等於零；不製作淨資產不完整的排行榜。不重製私人地址、帳戶等非必要資訊。
- 司法：同名不是身分證據；以案件案號、法院、審級、程序狀態與最新可確認文件為基礎。區分起訴、未確定判決、定讞、無罪、撤銷、行政裁罰。法定不得揭露及與公共職務無關資料不刊載。不得暗示無資料即無前科。
- 政策：原文與摘要分離；統一政策分類及欄位，列財源、量化目標、期限、權責，未知不扣分，不做立場優劣排名。
- 治理：以原始任期紀錄、職權與統計分母為基礎；出席率須揭露適用會議及請假處理，不以單一數量衡量治理績效。
- 政治獻金：原始申報、申報期間、修訂狀態及分類規則分離；不以捐款關係推定違法或交換利益。

## 來源級別

官方原始資料（確認官方公告內容）／本人正式聲明（僅確認其陳述）／第三方來源（注明來源及核實狀態）／方法公開的推估（不得當成事實）。同為官方資料也可能是依法刊登的候選人自述，必須依欄位性質標記。
