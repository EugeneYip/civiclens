# 候選人名冊查核計畫｜V0.2.0-alpha.1

本分支為開發測試，不得當作全國名冊或正式發布版。臺灣時間 2026-11-25 查核，六筆臺北市市長候選人，涵蓋同一選區全部正式號次，尚待獨立人工覆核。全國 19,100 人為中選會資格審定統計基準，不保證等於投票日最終名單。

## 原始來源與優先序
- 2026-09-07 [登記名冊](https://web.cec.gov.tw/central/article/64709)：登記者，不能視為正式候選人。
- [中選會答客問](https://info.cec.gov.tw/vote2026/article/content/?target=%2Farticle%2FA0096)：19,695 登記、594 資格不符、1 人死亡未審定、19,100 資格符合；11/12、11/17、11/22 分階段公布正式名單。
- [臺北市公告](https://web.cec.gov.tw/mect/article/65738)及[附件](https://web.cec.gov.tw/api/file/fda742f4-2d52-48b6-8b26-1c6c96d323ca.pdf)：姓名與號次以正式公告原始影像為準。
- [10/27 抽籤登記冊](https://www.cec.gov.tw/api/file/b74a02c0-b39e-4258-afd8-eb31787b0eb0.pdf)：姓名、號次及推薦之政黨；推薦政黨不等同目前黨籍。原文「無」僅表示無推薦政黨。
- 原始影像與自動擷取不同時，逐字核對影像及其他官方來源，不以模糊比對自動改名。
- 官方查詢入口：[電子公報](https://eebulletin.cec.gov.tw/?dir=115)、[選舉專區](https://info.cec.gov.tw/vote2026/)。

## 發布門檻
1. 逐選區建立官方公告清冊、預期候選人數與名冊版本。保留文件雜湊（本試作尚未取得原始 PDF bytes）、頁碼與擷取日期。
2. 名冊比對必須以選舉、縣市、職務、選區、號次組合唯一鍵。不得以姓名單獨合併。完整選區未對帳，不發布其中一部分。
3. 按公告號次排序、同一欄位同一標準。不呈現姓名以外不必要的個人資訊。
4. 依職務、縣市與選區分別對帳，分離缺漏、未審核、公告更正、重行選舉、候選人死亡及資格變更。所有差異保留原因。
5. 人工覆核及法律、資料再利用與治理揭露尚未完成；不得合併部署此分支。既有正式站維持 V0.1。
6. 若官方資料缺漏，顯示官方公報入口，不自行補造；更正依既有編輯規範處理。
