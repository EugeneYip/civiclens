# 編輯及治理規範（初版提案）

1. 不為任何政黨、候選人或政治立場背書；不以政治偏好改變收錄門檻、顯示順序或稽核強度。所有候選人按正式號次排序；跨選區依公開固定規則排序。
2. 不出售排名、搜尋權重或選民個資；不蒐集使用者政治偏好、定位或投票意向。本版無追蹤程式；外部網站另適用其隱私條款。
3. 不刊載未查證的指控、民調或勝選機率；不產生候選人綜合分數。投票日及法定期間應進行內容審查，不將靜態資訊網站視為當然免責。
4. 所有維護者、編輯、審查者之相關利益衝突應申報並迴避。正式公開前公布實際營運者、資金與利益關係；目前未建立獨立治理委員會，不能自稱經第三方認證。
5. 更正流程：使用儲存庫 issue 或經核准之私密通道，提供欄位、原始來源及理由；涉及個資不要公開張貼。先確認風險與原始證據，必要時暫時下架，公開非敏感更正摘要及日期。正式收件管道待建立。
6. 不因資料缺失而作負面暗示。提供候選人回應與異議機會，以相同規則審核及呈現。
7. 重大編輯規範變更須有版本紀錄，事前公告，不針對個案臨時修改。
